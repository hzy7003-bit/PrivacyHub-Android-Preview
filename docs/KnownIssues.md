# 已知问题

以下为 `0.10.2-beta`（versionCode `130`）仍需留意的系统与兼容性边界。

- 部分系统可能缓存覆盖升级前的通知图标；若应用信息已显示新花形、通知仍是盾牌，可先重开应用或刷新通知，仍无效时在方便时重启手机。一台 OriginOS 16 设备经重启并打开 App 后恢复；这不是全 ROM 保证，不必卸载或清除安全箱。
- 双按钮放在本条通知的紧凑内容中，但系统仍可能分组、裁切或隐藏整条通知；不保证“永不折叠”。
- 部分 ROM 会杀掉通知栏保存入口。
- 系统强制停止后的通知与后台恢复由 Android / ROM 控制；需要重新打开 App，并检查通知权限与后台策略。
- 部分 App 不支持或不展示 `ACTION_PROCESS_TEXT` 文本处理入口。
- 控制中心磁贴读取剪切板在不同 Android 版本和国产 ROM 上表现不一致。
- 如果用户禁用了通知权限，通知栏保存入口无法显示。
- 如果设备已安装 debug 包，release 包可能无法直接覆盖安装。
- 淘宝、网盘等第三方 App 可随版本调整 Deep Link，个别链接可能回退到浏览器。
- 系统自动填充依赖目标 App 或浏览器正确暴露 Autofill 字段，不能保证兼容所有登录页面。
- 网盘提取码辅助仍属于 Beta，页面结构与浏览器兼容性存在差异；需要用户主动开启专用无障碍服务，不会自动点击确认、登录或下载。
